# Factorial Experiment Design

Enumerate factor levels and interactions; use randomization and blocking to control nuisance variables.

1. State a falsifiable hypothesis and minimum meaningful effect.
2. Freeze a baseline and vary only prespecified factors.
3. Randomize trial order and retain every result, including failures.

Example:
```text
State a falsifiable hypothesis and minimum meaningful effect.
```

Check: Check independence assumptions, power, missing trials, multiple comparisons, effect sizes, and artifact completeness.
