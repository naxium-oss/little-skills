# Open-Source Implementation Pattern Research

Inspect licensed source implementations at pinned commits and distinguish patterns from copyable assets.

1. Observe the actual product workflow and record dated evidence.
2. Inspect repository constraints and reference licenses.
3. Compare alternatives with a bounded feasibility spike and prespecified success and rollback criteria.

Example:
```text
Observe the actual product workflow and record dated evidence.
```

Check: Report provenance, feasibility unknowns, implementation dependencies, accessibility, licensing, experiment results, and reasons not to build.
