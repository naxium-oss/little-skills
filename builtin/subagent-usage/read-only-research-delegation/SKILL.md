# Read-Only Research Delegation

Delegate source discovery without write privileges and require exact citations and retrieval dates.

1. Give each delegate a bounded question, artifact format, tool allowance, and budget.
2. Partition files or use isolated worktrees.
3. Independently verify claims and integrate results in dependency order.

Example:
```text
Give each delegate a bounded question, artifact format, tool allowance, and budget.
```

Check: Check provenance, duplicate effort, conflicting writes, token budget, and the escalation path when a delegate fails.
