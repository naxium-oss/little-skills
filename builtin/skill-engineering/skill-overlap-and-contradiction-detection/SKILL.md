# Skill Overlap and Contradiction Detection

1. Define one narrow trigger and explicit non-goals.
2. Declare prerequisites, tool permissions, evidence gates, and success criteria.
3. Exercise positive, negative, and ambiguous-trigger fixtures across intended models.
