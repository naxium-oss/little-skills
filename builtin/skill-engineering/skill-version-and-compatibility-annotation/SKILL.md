# Skill Version and Compatibility Annotation

Version the skill independently and document verified target combinations without claiming universal compatibility.

1. Define one narrow trigger and explicit non-goals.
2. Declare prerequisites, tool permissions, evidence gates, and success criteria.
3. Exercise positive, negative, and ambiguous-trigger fixtures across intended models.

Example:
```text
Define one narrow trigger and explicit non-goals.
```

Check: Track false-positive routing, procedure adherence, unsupported claims, overlap, and regression against the prior skill revision.
