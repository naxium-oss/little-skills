# Builtin skill library

These 1080 skills are 150-token cards for a small coding model. Each card keeps the
skill's rule, a few steps, one example, and a check. The long originals are in
`../skills-original-backup` and can be regenerated into cards with
`python scripts/compress_skills.py`.

1080 skills from three libraries. The first two are kept as imported sources; the third is expanded from
the library's own text. Sections below cover them in that order.

- **The Expansion Collection** (200 skills) - `https://01a08b9b-5d32-75c2-b96c-83705cd5fc67.arena.site/`
- **Skillstack** (480 evidence-first skills) - `https://01a086d2-ceb5-700d-9b6b-4e141adf662d.arena.site/`

Regenerate these two with `node scripts/import-arena-skills.mjs --set <skillset-export> --stack <skillstack-export>`
after downloading each library's ZIP. Collection folders are the hub the catalog reports. The Foundations library
(400 skills, section at the end) is regenerated differently - see that section.
