# Accessible Name and Description Verification

Inspect computed accessible names and descriptions rather than visible labels alone.

1. Confirm the requested WCAG edition and conformance level.
2. Map each interaction to semantics, accessible names, and focus behavior.
3. Combine automated checks with keyboard, screen-reader, zoom, and motion testing.

Example:
```text
Confirm the requested WCAG edition and conformance level.
```

Check: Do not equate a clean automated scan with conformance; report manual coverage, known failures, and untested combinations.
