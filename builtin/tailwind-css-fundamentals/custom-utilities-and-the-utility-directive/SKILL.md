# Custom Utilities and the @utility Directive

writing a plain global CSS.

1. Do not: writing a plain global CSS class instead of an @utility, losing automatic variant-prefix support.
2. Do not: duplicating an existing utility combination as a "custom utility" that Tailwind's own composition already.

```bash
npx tailwindcss --help | head -3
```
