# Currying and Partial Application

using a generic arity-based curry.

1. Do not: using a generic arity-based curry helper on a function with default or rest parameters.
2. Do not: over-currying trivial two-argument functions where the added indirection doesn't earn its complexity cost.

Example:
```bash
locate the effects: I/O, clock, randomness, mutation
```

Check: Do not: using a generic arity-based curry helper on a function with default or rest parameters, causing it.
