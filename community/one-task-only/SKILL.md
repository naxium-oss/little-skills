# One task

Do the asked change and stop.

1. Restate the one outcome.
2. Edit only that.
3. Mention the next task instead of doing it.

Example:
```text
Fixed the null guard. Did not also redesign the cart.
```

Check: A second improvement belongs in the reply, not the diff.
