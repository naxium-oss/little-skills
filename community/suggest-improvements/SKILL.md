# Suggest improvements

Improve what the code already does. Do not add a product.

1. Read the path they named.
2. List at most three changes that remove a real cost.
3. Say which one you would do, then stop.

Example:
```text
parse() is copied in a.ts and b.ts. Share one parse.
```

Check: Make it nicer is not an improvement. Name the defect.
