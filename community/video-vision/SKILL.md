# Video vision

Captions first. Frames only if captions cannot answer.

1. Resolve the URL.
2. Read captions before downloading frames.
3. Cite a timestamp for every visual claim.

Example:
```text
Frame at 0:12 shows the empty state. Caption does not mention it.
```

Check: Do not describe a frame you did not open.
