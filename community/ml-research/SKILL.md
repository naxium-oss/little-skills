# ML research

Compare the paper to a run. Do not trust the abstract alone.

1. Name the model, data, and metric.
2. Find the paper and the code that claims it.
3. Smoke-test the pipeline before a long run.

Example:
```text
Metric is exact match. Baseline is the paper's table 2.
```

Check: An abstract is not a result you measured.
