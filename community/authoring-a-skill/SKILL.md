# Author a skill

A skill is a short procedure with a trigger, not a story.

1. name is hyphen case. description starts with Use when and quotes real phrases.
2. Body: one rule, numbered steps, one example, one check.
3. Stay under 150 tokens. Split a second task into a second skill.

Example:
```text
Use when "off by one". Not when the loop is unwritten.
```

Check: A description that retells the steps will be followed instead of the body.
