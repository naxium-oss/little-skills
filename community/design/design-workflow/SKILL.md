# Design workflow

Load one design skill, then do only that step.

1. Who it is for: product-truth. Look: visual-direction.
2. Type or spacing: type-and-space. Color: color-and-contrast. Motion: motion-and-states.

Example:
```text
the spacing is off -> type-and-space. Do not restyle the brand.
```

Check: One section this turn. Render it before you say it looks right.
