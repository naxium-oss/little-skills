# Suggest features

Suggest at most three ideas, tied to code that exists.

1. Read one current user path.
2. Each idea names the user, the behavior, and the files.
3. Lead with the one you would build. Do not build it.

Example:
```text
Retry failed uploads in src/upload.ts. Build this one.
```

Check: An idea with no file is a slogan. Drop it.
