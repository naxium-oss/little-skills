# Clone from a reference

Copy observed behavior, not a memory of the product.

1. Write the rules a user can see.
2. Look them up when the repo does not already list them.
3. Build the smallest slice that follows the list.

Example:
```text
5 letters, 6 guesses, three tile colors. No extras yet.
```

Check: A rule you did not look up is an assumption. Say so.
