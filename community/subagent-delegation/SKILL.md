# Delegate a bounded job

Delegate wide reading or a check on your own diff.

1. Delegate when the result is a summary you can check.
2. Write a brief that stands without this chat.
3. Treat the summary as a lead. Open the files it names.

Example:
```text
Brief: find who writes sessions. Return file paths and one quote.
```

Check: Do not delegate one command you could run yourself.
