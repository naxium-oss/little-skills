# Execute the plan

Do one plan task, then its check, then stop or continue.

1. Read the whole plan and note which task is first.
2. Do that task only.
3. Run the check the plan names before the next task.

Example:
```text
Task 2 check failed. Stop. Do not start task 3.
```

Check: A skipped plan step is not done.
