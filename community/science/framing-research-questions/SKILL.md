# Frame the question

The entry gate for a scientific investigation.

1. Restate what the user asked as an interest, then as a question with a subject, a.
2. Write the falsifiable version: what result would make the answer "no".
3. Name the unit of analysis (patient, sample, cell, image, run), the comparison, and the outcome measure.

Example:
```text
Restate what the user asked as an interest, then as a question with a.
```

Check: The question cannot be made falsifiable with the data that exists: say so and propose the data that.
