# Write a science skill

One repeated procedure, under 150 tokens, with a check.

1. Description starts with Use when and quotes the user's words.
2. Three steps, one example, one stop if data is missing.
3. Skip it if the procedure has only been done once.

Example:
```text
Use when "label shuffle" should change the result.
```

Check: A body with no command and no file is advice. Cut it.
