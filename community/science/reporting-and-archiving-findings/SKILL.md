# Report and archive

A finding is finished when someone else can reproduce it from what you leave behind.

1. Run the reproducibility check first: from the archive alone, in a fresh process, one command regenerates.
2. Write the report in this order: question, what was done, what was found with uncertainty, what.

Example:
```text
Run the reproducibility check first: from the archive alone, in a fresh process, one.
```

Check: No negative or null result may be dropped from the report.
