# Survey what is already known

Before designing an analysis, find out which version of it has.

1. Run papers_search and web_search_multi on the question's own words, then on the method name.
2. For each source, record: what was measured, in which population or system, with which method, and.

Example:
```text
Run papers_search and web_search_multi on the question's own words, then on the method name.
```

Check: No source addresses the question: that is a finding.
