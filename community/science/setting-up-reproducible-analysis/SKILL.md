# Set up a reproducible workspace

An analysis whose environment is unknown is an anecdote.

1. Lay out data/raw/, data/derived/, code/, results/, and preregistration/.
2. Create the environment from a file, not from memory.

Example:
```text
Lay out data/raw/, data/derived/, code/, results/, and preregistration/.
```

Check: Raw data would have to be modified to proceed: stop and ask.
