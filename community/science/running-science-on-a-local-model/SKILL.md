# Science on a small model

One step, one printed result, then stop.

1. Name the step and the command before you run it.
2. Quote the number from this turn's output.
3. Write it into NOTES.md so the next turn does not recall it.

Example:
```text
Printed n=42 from the script. Wrote 42 in NOTES.md.
```

Check: A number you did not print this turn is unknown.
