# Diagrams

One HTML file, inline SVG, one diagram type.

1. Pick flowchart, sequence, state, ER, or timeline.
2. Put nodes on a grid. Label the arrow.
3. Import draw.io by mapping shapes, not by tracing a picture.

Example:
```text
Box A to box B labeled pays. No gradient and no shadow.
```

Check: Two diagram types in one frame means two files.
